# Privacy, by platform

Muses has different playback and account implementations on each platform. Use the policy for the app you install.

- [macOS — Polyhymnia](macos-privacy.html): local library, macOS Keychain, native playback and optional isolated Web Home helper.
- [iOS — Erato Public](ios/privacy.html): official visible YouTube player, Google sign-in, local library, recovery copies and deletion controls. [Terms of use](ios/terms.html).
- [Windows — Euterpe](windows-privacy.html): local SQLite library, platform credentials, native playback and optional Web Home helper.

The website serves static pages and local screenshots without analytics or an embedded player. GitHub processes website requests under its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). External download, source and provider links open those services.
