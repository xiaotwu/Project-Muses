## 8. 全计划统一验收门槛

以下为拟定验收阈值，尚非实测结果。P0 固定测试设备、网络条件与素材，并检验阈值是否合理；后续不能在失败后静默放宽。

| 维度 | 完成门槛 |
| -- | -- |
| 点击到真实首声 | 对同一组 ≥30 个预先标注的可用曲目，做 ≥100 次受控冷点播；参考目标 p50 ≤2.5s、p95 ≤5s，观测成功率 ≥99%。全部尝试计入，网络／来源拒绝另列原因；这是样本结果，不是总体可靠性保证。Mac 0.6.3 与新版本同机比较。 |
| 连播与恢复 | 每个发行候选至少 2 次各 4 小时播放，覆盖网络波动、路由改变、暂停恢复和手动插队；0 个由播放器造成的崩溃、队列错位、重复推进和不可恢复中断。真实声音和进度同时核验。 |
| 切歌和无缝 | 已准备下一首手动切换 p95 ≤750ms；同采样率的连续校准素材在内部 PCM 边界无丢帧／重复帧，输出端记录可归因的间隙，目标额外间隙 ≤20ms。淡化曲线／增益／交接点有音频证据；不同采样率与编码延迟单列。 |
| 重开／崩溃 | 正常退出恢复位置偏差 ≤1s；异常退出相对最近持久化检查点的损失有上限并实测，目标 ≤5s。保存的暂停意图、队列实例和顺序准确；退出不会留下继续播放的自有工作。 |
| 搜索、身份、同步 | 标注样本覆盖中英日、同名、不同版本、长分页、MV、不可用项；不存在已知的静默错曲替换。远端操作故障注入后无重复成员、无误删及无丢失用户修改，所有未决状态可解释。 |
| 数据 | 旧→新实体、稳定身份／映射、成员及顺序、喜欢、历史、备注、进度全量核对；迁移中断可继续或回退；备份恢复可重现。对故意变化逐项说明，不靠整库文件哈希判断业务等价。 |
| 离线与容量 | 断网冷启动播放已完成下载；续传 Range／ETag／长度变化正确处理；损坏／过期权限有状态。磁盘不足、取消和进程结束不产生可见半文件；缓存清理不删显式下载和使用中文件。 |
| 音频与 AutoMix | 自有／允许测试素材核验时间轴、EQ／增益、采样率切换、速度与变调；盲听或用户试听确认主要场景。AutoMix 低置信度回退可重现；bit-perfect 在宣称设备上验证，不能用 UI 标签代替。 |
| 资源 | 实时线程无网络／数据库／无界分配；50 次切歌／后台循环后无持续线性内存增长（RSS、缓存高水位与误差分别记录）。核心普通双路 PCM 池预算 ≤32MiB、解析 runtime 初始上限 64MiB，例外需明确调整预算；电池与发热在手机真机测量。 |
| 生态与多人 | 来源或账号撤销后不再请求；上报重试可去重。一起听以时钟估计误差、实际输出延迟和多设备偏移共同测量；有线／同网参考目标 p95 ≤250ms，蓝牙和广域网单列。用户离开房间后恢复独立播放。 |
| 内嵌视频 | 视频在主界面内播放；宽／窄窗口及手机布局完整，画面比例正确，按钮可触达；进入、暂停／seek、换曲、导航、关闭、全屏往返及失败重试均正确。无双重声音／重复控制权，音视频位置按时间轴映射处理，返回音频符合保存的播放意图，键盘／焦点可恢复。 |
| UI 与系统 | 已选主路径在 light/dark、高对比、Reduce Motion/Transparency、键盘与屏幕阅读器通过；原视觉基准得到保留。媒体键／锁屏与应用状态一致；辅助窗口只有一套播放权威。 |
| 发布与维护 | 构建、功能测试、真实原生、可听、签名／公证分别留证；Mac、iOS、Windows 各自过关。无未解决的关键数据丢失、错播、凭据泄漏或基础主路径阻断；中低优先级已知问题必须公开列明。 |

测试覆盖：领域状态机与不变量、属性／序列测试、协议 fixture、适配器集成、时间／网络／磁盘故障注入、数据迁移、真实原生旅程和试听。复用旧测试所表达的用户行为；删除只固定旧架构的断言。对已经通过且未受影响的路径不机械重复；重大核心／平台变更需要对应回归。
